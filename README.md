# 论文/作业格式检查与修复系统

本地运行的 `.docx` 格式检查与修复工具。核心检查不联网、不需要 API Key。

## 运行环境

- Python 3.10 或更高版本
- Windows、macOS 或 Linux

## 首次安装与启动

Windows 用户直接双击 `启动系统.bat`，默认打开浏览器版。启动器会使用一个仅用于本系统的 Edge 窗口直连本机服务，不改动 Windows 的全局代理设置。

如浏览器被单位设备策略限制，可使用 `启动桌面备用.bat` 打开本地备用界面；该模式不替代浏览器版。

在本项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py
```

浏览器访问 <http://127.0.0.1:5000>。默认只允许本机访问；如确实需要局域网演示，可在启动前设置 `PAPER_CHECKER_HOST=0.0.0.0`，并仅在可信网络使用。

首次进入请用邮箱地址注册本地账号，密码至少 10 个字符。邮箱仅作登录名：当前不发验证邮件，也没有邮件找回密码。请妥善保存密码；账号数据库和会话密钥保存在项目的 `data/` 中，不要公开或删除。不要把此版本直接部署到公网。

## 页面与功能

- `/`：格式检查与修复工作台，支持模板选择、格式要求本地解读、DOCX 检查和修复副本下载。
- `/guide`：独立的格式指南页面，说明模板参数、使用流程和自动检查的边界。
- `/similarity`：独立的资源页面，提供知网、万方、大雅的查重入口和万维书刊网的投稿信息入口，不进行站内查重或代传论文。
- `/profile`：设置当前账号的显示名称和内置头像；邮箱仍是登录名。
- `/history`：按账号查看检查与修复记录、打开尚未过期的报告/修复稿，或主动删除记录及仍保留的文件。
- `/comparison/<任务ID>`：仅任务所属账号可访问的修复前后对照页，可查看每处修改前后的值、筛选分类、核对剩余问题并下载修复副本。
- 投稿信息区另增国家科技期刊平台和 LetPub 期刊查询入口；它们只是选刊/投稿信息参考，正式投稿应核对目标期刊官网。
- 三个页面均可切换日间/夜间模式；主题偏好只保存在当前浏览器的本地存储中。

查重平台可能需要注册、机构权限或付费。务必以学校指定平台和要求为准，上传未公开论文前自行核对平台域名与隐私条款。

## 在同一网络的其他电脑打开

在作为服务端的电脑上双击 `局域网共享启动.bat`。窗口会显示类似 `http://192.168.x.x:5000` 的地址；其他连接**同一 Wi-Fi、同一局域网或同一校园网且未开启客户端隔离**的电脑，在浏览器输入这个完整地址即可使用，无需安装 Python 或复制项目文件。

首次使用如对方无法访问，请双击 `配置局域网防火墙.bat`，在 Windows 的管理员确认窗口中允许它添加一条仅限“专用网络”的 TCP 5000 入站规则，然后重新启动共享模式。共享期间请保持启动窗口开启；按 `Ctrl+C` 即可停止。不要在公共 Wi-Fi 或不可信网络启用此模式。

异地、不同网络的设备不能直接使用局域网地址。此时需要另行选择受控的公网部署或临时隧道，并应先确认论文文件的隐私与保留策略。


## 数据处理与安全边界

- 每次上传会生成独立随机任务目录，避免同名文件覆盖。
- 报告、修复稿和对照页仅允许上传该任务的登录账号访问；密码使用 scrypt 哈希保存，登录失败有临时次数限制。
- 当前邮箱注册未验证邮箱所有权，也没有找回密码、管理员审核和公网部署所需的完整安全防护。局域网演示仍请仅在可信网络使用。
- 上传文件、报告和修复稿默认保留 24 小时，后续上传时清理已过期任务。
- 历史记录摘要保存在本机账号数据库中，不会随任务文件过期而消失；过期任务的下载链接会消失。可在“我的历史”手动删除记录。
- 仅接受实际为 Office Open XML 容器的 `.docx` 文件，大小上限 50MB。
- AI 润色在本地版中默认关闭，避免把 API Key 和论文文本发往未经审计的中转服务。

## 已知边界

该工具适合标准正文、标题、参考文献和表格表头的检查与修复。复杂文档（目录、文本框、批注、脚注、公式、页眉页脚及高度定制样式）应先备份原稿，再逐项确认修复记录。
